# StudyAgent 文档中心

本目录存放 StudyAgent 的产品边界、技术方案、接口说明、数据模型和部署文档。文档应与代码一起版本化，涉及范围、接口或数据结构的变更必须同步更新对应文档。

## 目录约定

```text
docs/
├── 文档索引.md
├── 技术方案/         # 产品边界、系统架构、Agent、数据与迁移方案
├── 接口文档/         # HTTP/SSE API、错误码、请求响应示例
├── 部署文档/         # 本地开发、Docker Compose、生产部署与运维
└── 架构决策/         # 重要架构决策记录（ADR）
```

只在有实际内容时创建“接口文档”“部署文档”和“架构决策”中的文件，避免先堆积空模板。

## 文档原则

1. 以个人学习闭环为核心，不以复刻旧系统为目标。
2. “不做什么”必须和“做什么”同样明确。
3. 方案先满足单用户本地运行；未来能力通过边界扩展，而不是提前实现。
4. LLM 负责理解与生成，程序负责权限、校验、状态迁移和数据库写入。
5. 所有题目、判题和讲解必须能追溯到原始资料。
