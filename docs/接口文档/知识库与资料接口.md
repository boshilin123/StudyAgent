# 知识库与资料接口

状态：P1、P2 已实现  
依赖：[接口总览](接口总览.md)

## 1. 创建知识库

`POST /api/knowledge-bases`

请求：

```json
{
  "name": "系统架构设计师",
  "description": "考试教材与个人笔记",
  "language": "zh-CN"
}
```

响应 `201`：

```json
{
  "id": "2a9b77f5-4acf-4fd3-8fbd-eaf803083e1c",
  "name": "系统架构设计师",
  "description": "考试教材与个人笔记",
  "language": "zh-CN",
  "status": "active",
  "material_count": 0,
  "question_count": 0,
  "created_at": "2026-09-27T08:30:00Z",
  "updated_at": "2026-09-27T08:30:00Z"
}
```

约束：`name` 长度为 1–200；同名知识库允许存在，但前端应提示。

## 2. 查询知识库列表

`GET /api/knowledge-bases?page=1&page_size=20&status=active&keyword=架构`

查询参数：

- `page`：默认 1。
- `page_size`：默认 20，最大 100。
- `status`：`active` 或 `archived`。
- `keyword`：按名称模糊搜索。

返回通用分页结构，列表项包含资料数、启用题目数和最近学习时间。

## 3. 查询知识库详情

`GET /api/knowledge-bases/{id}`

响应与列表项结构一致，包含当前已实现的资料数和题目数聚合统计：

```json
{
  "id": "2a9b77f5-4acf-4fd3-8fbd-eaf803083e1c",
  "name": "系统架构设计师",
  "description": "考试教材与个人笔记",
  "language": "zh-CN",
  "status": "active",
  "material_count": 3,
  "question_count": 128,
  "created_at": "2026-09-27T08:30:00Z",
  "updated_at": "2026-09-27T09:00:00Z"
}
```

## 4. 更新知识库

`PATCH /api/knowledge-bases/{id}`

允许修改 `name`、`description`、`language` 和 `status`。归档知识库后不能创建新的学习会话，但历史数据仍可查询。

## 5. 上传资料

`POST /api/knowledge-bases/{id}/materials`

请求类型：`multipart/form-data`

- `file`：必填。
- `title`：可选；默认取原文件名。
MVP 支持 PDF、DOCX、PPTX、TXT、Markdown，以及结构清晰的 XLSX。文件大小上限由配置项 `MAX_UPLOAD_SIZE_MB` 决定，默认 100 MB。

响应 `202`：

```json
{
  "material": {
    "id": "73976b75-fd18-4892-858d-053008704353",
    "knowledge_base_id": "2a9b77f5-4acf-4fd3-8fbd-eaf803083e1c",
    "title": "第01章 绪论.pdf",
    "original_filename": "第01章 绪论.pdf",
    "media_type": "application/pdf",
    "sha256": "7b7e...",
    "size_bytes": 1872210,
    "language": "zh-CN",
    "parse_status": "pending",
    "parser_version": null,
    "error_message": null,
    "created_at": "2026-09-27T08:30:00Z",
    "updated_at": "2026-09-27T08:30:00Z"
  },
  "job": {
    "id": "aa1a49c8-b937-4c22-becf-a8b8c8213698",
    "status": "pending",
    "stage": "uploaded",
    "progress": 0,
    "generation_config": {},
    "error_code": null,
    "error_message": null,
    "started_at": null,
    "finished_at": null,
    "created_at": "2026-09-27T08:30:00Z"
  }
}
```

失败场景：

- `UNSUPPORTED_FILE_TYPE`
- `INVALID_MEDIA_TYPE`
- `FILE_TOO_LARGE`
- `EMPTY_FILE`
- `DUPLICATE_MATERIAL`
- `STORAGE_UNAVAILABLE`

服务端先计算 SHA-256，再写入 S3 兼容对象存储和数据库。同一知识库中内容哈希相同的文件默认返回 `409 DUPLICATE_MATERIAL`。上传成功后自动提交 Celery Chain，依次执行解析、切块、Embedding 和 Milvus 入库。

## 6. 查询资料列表

`GET /api/knowledge-bases/{id}/materials?page=1&page_size=20&status=ready`

列表项返回资料完整元数据。查询参数 `status` 对应响应字段 `parse_status`，可取 `pending`、`parsing`、`ready`、`partial` 或 `failed`。任务进度通过处理任务接口单独查询。

## 8. 重新处理资料

`POST /api/materials/{id}/reprocess`

响应 `202`，返回新的资料处理任务。接口复用对象存储中的原文件，重新执行解析、切块、Embedding 和 Milvus 入库，适用于切换 Embedding 模型、向量维度、切块策略或解析器版本后的索引重建。

相同内容生成的片段采用稳定 ID 并原位更新，以保留仍然有效的题目来源关系；只删除已经失效的片段。若资料已有运行中的处理任务，返回 `409 MATERIAL_JOB_RUNNING`。

## 9. 删除资料

`DELETE /api/materials/{id}`

响应 `204`。由 application service 删除 Milvus 向量、对象存储文件并物理删除资料记录，数据库关联记录通过外键级联清理。若资料已有运行中任务，返回 `409 MATERIAL_JOB_RUNNING`。

删除资料时会先清理 Milvus 原文向量，再删除对象存储文件和数据库记录。P3 接入题目来源后，再补充失去全部来源时的题目停用规则。

## 10. 查询处理任务

`GET /api/ingestion-jobs/{id}`

```json
{
  "id": "aa1a49c8-b937-4c22-becf-a8b8c8213698",
  "material_id": "73976b75-fd18-4892-858d-053008704353",
  "status": "running",
  "stage": "embedding",
  "progress": 63,
  "generation_config": {},
  "error_code": null,
  "error_message": null,
  "started_at": "2026-09-27T08:31:00Z",
  "finished_at": null,
  "created_at": "2026-09-27T08:30:00Z"
}
```

`progress` 只用于展示，最终结果以 `status` 和资料状态为准。错误对象仅返回安全摘要，完整堆栈写入服务端日志。

## 11. 查询资料片段

`GET /api/materials/{id}/chunks`

按 `chunk_index` 返回资料片段，包含正文、估算 Token 数、页码范围、标题路径、内容哈希、向量 ID 和 Embedding 模型。资料尚未完成解析时返回空数组。

## 12. 检索原文

`GET /api/knowledge-bases/{id}/search?q=TCP三次握手&limit=5&material_id={material_id}`

- `q`：必填，长度 1–1000。
- `limit`：默认 5，最大 20。
- `material_id`：可选；限定只检索一份资料。

响应返回片段 ID、资料 ID、正文、相似度、页码和标题路径。当前是 Dense Retrieval 基线，不包含 Rerank、混合检索或查询改写。
