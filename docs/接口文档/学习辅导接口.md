# 学习辅导接口

日期：2026-10-01。本次三项升级新增的非流式辅导接口；实施与验收结果另见验收报告。

## 会话

`POST /api/tutor/conversations` 创建会话，输入 `knowledge_base_id`，可选 `study_session_id` 和 `answered_question_id`。答后题目必须属于该学习会话且数据库已有真实作答。知识库与题目绑定创建后不改变。

`GET /api/tutor/conversations?knowledge_base_id=...&page=1&page_size=20` 获取分页会话列表。

`GET /api/tutor/conversations/{id}?page=1&page_size=50` 返回 `conversation`、分页 `messages`、`page`、`page_size`、`total`。消息带稳定 `sequence`，引用的当前有效性重新核对。

`POST /api/tutor/conversations/{id}/archive` 归档会话；历史可查看，不能继续运行。运行中的会话不得通过归档破坏状态。

## 提问与恢复

`POST /api/tutor/conversations/{id}/messages`：

```json
{
  "client_message_id": "00000000-0000-4000-8000-000000000001",
  "content": "结合最近错题，解释我容易混淆的概念。",
  "intent": "mistakes"
}
```

问题类型 `intent` 为 `materials`、`answered_question`、`progress`、`mistakes` 或 `general`。类型影响所需取证，不解除服务端权限校验。

响应带 `turn_id`、`status`、`message`、`answer_status`、`mode`、`citations`、`suggestions`、`suggested_questions`、`usage`、`idempotent_replay`、`error_code`、`error_message`。模型内容按文本展示，引用标题、页码和原文由服务端生成。

`GET /api/tutor/conversations/{id}/turns/{turn_id}` 查询轮次及其已提交 `response`。

- 相同消息 ID、相同载荷：完成后重放；执行中返回 202 并提供轮次查询信息，不再次调用模型。
- 相同消息 ID、不同载荷：409 冲突。
- 超时或响应丢失：保存原 ID 与输入，用原 ID 重发，或查询已知轮次 ID。
- 明确失败或取消：相同 ID 不自动重跑；用户点击“重新尝试”时生成新 ID。
- 用量缺失：Token 标为不可用，不显示成零消耗。

前端将待确认请求保存在本地，刷新后恢复。原学习作答 ID 与辅导消息 ID 独立。

## 功能边界

辅导工具只读当前绑定知识库的资料、学习进度、最近错题及已作答题，不修改成绩、掌握度或复习计划。未作答题不开放专属解析；当前知识库存在未结束模拟考试时限制新辅导运行。问题和必要资料会发送到配置的模型供应商。

沿用共享访问令牌、`X-Request-ID` 与统一错误结构。关闭辅导、模型不支持工具调用、检查点不可用、调用预算耗尽、资料不足、知识库或引用失效，都应有明确提示。具体状态码与机器可读字段以 OpenAPI 和自动化验收为准。

供应商拒绝会在失败轮次中返回安全的固定提示：`TUTOR_MODEL_UNSUPPORTED` 表示明确拒绝工具能力；`TUTOR_MODEL_CONFIGURATION_INVALID` 表示思考模式与强制结构化工具选择冲突；其他参数拒绝使用 `TUTOR_PROVIDER_REQUEST_REJECTED`。不会返回供应商原始请求或错误正文。DeepSeek 原生参数配置见 [部署与恢复](../技术方案/学习辅导Agent部署与恢复.md)。

`TUTOR_THREAD_BUSY` 表示同一会话已有执行。前端保留待确认消息 ID，恢复时复用该 ID；不能仅因占位暂不可见就换 ID 再次运行。
