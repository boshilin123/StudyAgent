# StudyAgent 前端使用说明

## 知识库管理与生成结果

知识库右上角提供“删除知识库”。确认后软删除：从知识库和题库列表隐藏，停止新的学习与辅导，资料、题目及关联历史保留；“归档”仍用于暂时停用并可恢复。删除确认可以取消。

资料旁的“生成题目”打开设置，可选择 1–100 道、题型和 1–5 难度范围。6 道是前端初始目标，实际数量取决于模型返回、质量/原文引用校验及重复题复用。资料下方显示最近一次生成任务的目标、通过和拒绝数量，刷新后仍能查看；数量不足明确显示，不把目标数量当成实际题库数量。通过题默认待审核，启用后才能开始学习。

题库默认“全部知识库”汇总全部主题；选择单个知识库后显示该主题的实际题目数量。生成结果中的“查看该知识库题目”会自动限定主题。

生成结果中的“查看拒绝详情”显示未入库候选题及校验失败原因。新任务保留题干、答案、解析和引文；旧任务未保存的候选题内容不能还原。候选内容未通过校验，不能作为可靠答案或原文依据。它与题库状态筛选中的“已拒绝”分开记录。

题库卡片和题目详情都提供删除按钮，点击后需要确认，可取消。确认后退出题库、更新题目数量并清理检索索引，已有作答与学习历史保留。删除的题目不能继续作答，也不能通过编辑或启用恢复；后续生成相同题目不会自动重新入库。

页头“API 可用”来自 `/api/health/ready`，检查 API 以及数据库、队列、索引和存储，每30秒更新，可点击重新检查；它不代表模型供应商一定可用。页面不再显示重复的英文装饰标题。

## 学习辅导

导航“学习辅导”进入 `/tutor`。选择知识库并新建会话，按“资料问答”“学习进度与复习建议”或“近期错题分析”提问。会话固定绑定知识库；切换主题需新建会话。

学习作答结果页的“继续请教”绑定刚才已答题目，使用“答后追问”模式。模拟考试未结束时不提供该入口，后端同时验证限制。

消息提交后会保存待确认请求 ID。刷新、网络超时或响应丢失时，可恢复待确认消息，沿用原 ID 避免重复模型调用。已明确失败时点击“重新尝试本次问题”产生新轮次。会话归档后保留历史，停止发送。

辅导面板高度随窗口调整，消息历史在面板内部滚动，输入框始终留在下方。打开会话或刷新后定位最新消息；停留在底部时自动跟随新回复，向上翻看历史时保留位置，并提供“查看最新回复”按钮。历史分页切换从该页顶部阅读，侧栏会话列表单独滚动。长回复和展开资料引用不会持续撑高整页。

“查看资料依据”展开原文、材料名与页码；来源被删除或重解析后标明失效。模型回复按纯文本显示。复习建议供用户参考，不会自动修改复习任务。Token 用量缺失时显示不可用。

问题和必要资料会发送给配置的模型供应商。辅导依赖支持工具调用的模型及已初始化的 PostgreSQL 检查点；不可用时页面给出明确错误。

## 1. 访问地址

使用 Docker Compose 启动后访问 <http://localhost:55173>。前端默认通过 Vite 代理访问 `/api`，本地不需要额外配置 API 地址。

页面包括：首页、知识库、题库、开始学习、学习进度。

## 2. 推荐操作顺序

1. 在“知识库”创建个人知识库。
2. 上传 PDF、DOCX、PPTX、TXT、Markdown 或结构化 XLSX 资料。
3. 等待资料处理进度达到 100%，失败时查看页面错误信息和处理阶段。
4. 从已完成的资料创建题库生成任务。
5. 在“题库”核对题干、答案、解析和原文来源，再启用合格题目。
6. 在“开始学习”选择知识库、模式、题型和难度后开始作答。
7. 作答后查看判题结果、讲解和原文引用；在“学习进度”查看掌握度、复习计划和历史。

## 3. 会话恢复

前端把当前活动会话 ID 保存在浏览器本地存储中。刷新或重新打开学习页面时，会调用后端会话详情接口恢复当前题目和进度。Redis checkpoint 丢失时，后端会使用 PostgreSQL 中的事实数据重建状态。

会话已经完成、主动结束或后端确认不存在时，本地活动会话会被清理，页面回到学习设置。

## 4. 页面功能边界

学习辅导侧栏的每个会话都有“重命名”和“删除”按钮，使用中和已归档的会话均可操作。
名称去掉首尾空格后需为 1–100 字符，保存后列表与当前会话标题同步更新，刷新后保留。
删除需要确认；删除当前会话后自动选择剩余会话，列表为空时回到新建提示，分页末页为空时返回有效页。
删除采用软删除，列表、详情和提问入口均不可再访问该会话；内部保留消息、轮次和检查点用于审计，不影响知识库、题目、成绩、掌握度或复习记录。
归档会话仍能查看历史，删除会话则从界面隐藏。正在回复或有待确认消息时暂时禁止管理操作。
重命名和删除只更新本地应用数据库，不调用模型 API。

- 当前题型仅包含单选、填空和判断题，均由确定性规则判分。
- 错题可以触发 LangChain 引用讲解；正确题直接返回题库解析，避免不必要的模型调用。
- 当前讲解使用普通 HTTP 响应，不使用 SSE；只有真实长文本流式需求出现时再增加流式协议。
- 题目默认以草稿保存，需要人工核对来源后启用，学习工作台只选择已启用题目。
- 项目是单用户个人学习工具，不包含账号、组织、分组和权限管理。

## 5. 常见问题

### 页面没有可选知识库

先在“知识库”创建至少一个未归档知识库。

### 开始学习时提示没有可用题目

确认该知识库至少有一道已启用题目，并检查题型、难度筛选是否过窄。复习模式还要求存在到期复习任务。

### 上传后长时间没有进度

执行 `docker compose ps` 检查 API、Worker、Redis、Milvus 和对象存储是否运行，再通过处理任务接口或容器日志定位具体阶段。

### 刷新后没有恢复会话

浏览器本地存储可能已清理，或者会话已经完成。可在“学习进度”的历史记录中确认会话状态，然后重新开始学习。
