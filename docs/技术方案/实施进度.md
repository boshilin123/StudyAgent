### P5：自适应选择与检索讲解

- `practice`、`diagnostic` 和 `review` 改为逐题动态选择；`mock_exam` 保持开局固定题集。
- 实现掌握度、复习到期、最近错误、历史新鲜度、难度匹配、来源质量和题型多样性的确定性评分。
- 每次选题保存 `selection_reason` 和 `priority_score`，相同数据和配置产生可复现结果。
- 排除本轮已选题目；答错时优先匹配同知识点的较低难度题，同知识点连续补弱最多两道。
- 使用 LangChain `ChatPromptTemplate + PydanticOutputParser` 实现错误讲解，引用由程序绑定真实 `question_sources`。
- 正确答案不调用模型；模型失败时降级到题库解析，不能影响已经提交的判题事务。
- 将讲解结果持久化到作答记录，幂等重放不重复调用模型。
- Redis 保存当前题目、已选/已答题目、最近结果、薄弱点、剩余题数和下一动作，缓存丢失时从 PostgreSQL 自动重建。
- 新增 `0004` 数据库迁移，开放 `diagnostic` 模式并增加选题原因与讲解结果字段。
