# StudyAgent 评测基线与结果

更新时间：2026-09-28  
状态：P8 外部模型基线已完成

## 1. 评测原则

- 输入数据集、评测脚本和结果 JSON 一起保存，不能只保留结论。
- 确定性结构指标与需要人工判断的质量指标分开统计。
- 当前结果只代表指定小样本、模型配置和本机环境，不外推为生产指标。
- 更换 Embedding、切块、Prompt、模型或数据集后必须生成新结果，不能覆盖旧结果。

## 2. 运行命令

先启动完整开发环境，再运行：

```powershell
$env:EMBEDDING_PROVIDER='local'
$env:EMBEDDING_MODEL='deterministic-local-v1'

.\apps\api\.venv\Scripts\python.exe .\scripts\评测基线.py retrieval `
  --dataset .\evaluation\datasets\TCP检索基线-v1.jsonl `
  --output .\evaluation\results\TCP检索基线.json

.\apps\api\.venv\Scripts\python.exe .\scripts\评测基线.py questions `
  --knowledge-base-id d5737c62-e131-461b-9b9f-c602e59d6f0b `
  --output .\evaluation\results\TCP题库审计.json
```

检索评测会调用真实 `/search` 接口并记录每条召回结果和耗时。题库审计会读取真实题库接口，不调用 LLM。

## 5. 指标实现

- `Hit@K`：前 K 个结果是否至少包含一个相关片段。
- `Recall@5`：每条查询在前 5 个结果中召回的相关片段比例，再取平均。
- `MRR`：第一个相关片段排名倒数的平均值。
- P50/P95：按最近秩方法统计真实 HTTP 请求耗时。
- Schema 合法率：按三种题型的题干、答案、选项规则执行确定性校验。
- 来源关联率：题目是否至少绑定一个 `question_sources` 记录。
- 精确重复率：规范化题干后统计完全重复项；不等同于语义重复率。

指标实现位于 `study_agent/evaluation/metrics.py`，对应单元测试位于 `tests/test_evaluation_metrics.py`。
