# 个人项目最终简历稿

更新时间：2026-10-03

## 项目：基于 RAG 与 Agent 的个人自适应学习陪练平台

**技术栈：** Python、FastAPI、Vue 3、LangChain v1、LangGraph、Milvus、PostgreSQL、Redis、Celery、Docker Compose

**项目描述：** 面向个人学习与备考，支持上传资料自动生成题库，结合自适应练习、错答讲解、Agent 多轮辅导与复习计划，形成学习闭环。

**核心工作：**

- **学习辅导 Agent：** 构建 Tool Calling 与 RAG 结合的辅导 Agent，封装资料检索、作答上下文、学习进度与错题查询四类工具；通过 Runtime Context 绑定访问范围、Middleware 强制必需取证，结合结构化输出与 Evidence Ledger 校验返回格式和引用来源，使用 PostgreSQL Checkpoint、会话级执行锁及请求幂等实现多轮状态恢复与失败回合隔离。
- **资料解析与自动出题：** 使用 Celery 异步解析 PDF、Word、Excel 等资料，接入 1024 维 Embedding 与 Milvus 建立原文和题库双索引；通过结构化输出完成知识点抽取及三类客观题生成，校验来源引用后入库。
- **自适应练习与复习：** 根据掌握度、近期错答、难度匹配和复习到期信息加权选题，支持诊断、练习、复习和模拟四种模式，结合简化 SM-2 动态更新复习计划。
- **可靠判分与错答讲解：** 采用确定性规则判分，基于原文证据生成 LLM 错答讲解，异常时降级为题库解析；通过 PostgreSQL 事务与请求幂等保证重复提交不重复记分。

## 面试展开说明

- 题库生成是程序编排的 Chain；学习辅导是模型参与工具选择的单 Agent。开发时使用的四个 subagent 属于开发与验收分工，不代表产品运行时采用多 Agent 架构。
- Redis 保存可重建的学习会话快照；LangGraph 的辅导执行检查点保存在 PostgreSQL，两者职责不同。
- Agent 工具只读资料与学习事实；判分、掌握度更新和复习安排由确定性业务逻辑负责。
- 已建立可复现评测、后端与浏览器自动化验收，并使用 Docker Compose 编排运行依赖。可在面试时结合具体测试记录展开，不将小样本结果描述为通用质量或生产性能。

## 可使用的真实数据

- 30 条固定标注查询的外部 Embedding 基线：Hit@1、Recall@5、MRR 均为 1.0，P50 约 400ms、P95 约 600ms。
- 59 道生成题：Schema 合法率 100%、来源关联率 100%、精确重复率 0%。
- 自动化端到端验收覆盖 8 个关键环节并成功完成 3 道题学习闭环。

以上指标只对应当前固定小样本和本机环境。检索语料只有 3 个 TCP 片段，因此面试或简历中必须同时说明范围，不表述为通用生产性能。59 道题的人工审核率尚未填写，不能声称人工通过率。
