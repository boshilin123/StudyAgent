## 项目：基于大模型与 RAG 的个人自适应学习陪练平台

**技术栈：** Python、FastAPI、Vue 3、LangChain、OpenAI-compatible LLM、Milvus、PostgreSQL、Redis、Celery、S3 兼容对象存储、Docker Compose

**项目描述：** 面向职业技能学习与考试备考场景，支持上传 PDF、Word、PPT、Excel、Markdown 等个人资料，通过大模型完成知识点抽取和客观题生成，并结合 RAG、自适应选题、确定性判分、引用讲解、掌握度和复习计划，形成“资料解析 → 自动出题 → 学习练习 → 进度评估”的闭环。

**核心工作：**

- 设计基于 LangChain LCEL 与结构化输出的题库生成 RAG 工作流，将知识点抽取、单选/填空/判断题生成、来源引用验证、质量门禁和持久化拆分为受控阶段；使用 Celery 执行长任务并记录阶段、进度、失败原因与生成轨迹。
- 建立资料双索引链路，对多格式文档进行解析、切块和元数据保留，将原文片段与题目分别写入 Milvus；接入百炼 `text-embedding-v4` 1024 维向量，处理字符串输入和单批 10 条限制，并支持模型或维度变化后的资料重建索引。
- 实现客观题学习闭环与可解释自适应选题，根据掌握度、复习到期、历史新鲜度、难度匹配和题型多样性动态选择下一题；使用 PostgreSQL 保存学习事实、Redis 保存可重建 checkpoint，并通过简化 SM-2 更新复习计划。
- 实现可追溯判题与讲解：单选、填空和判断题采用确定性规则判分，答错时通过 LangChain 基于题目来源片段生成讲解，模型失败自动降级为题库解析，避免生成式判分影响学习事实。
- 建立可复现评测和验收体系，保存数据集哈希、模型配置、逐条召回与耗时结果；在 30 条固定 TCP 标注查询上完成外部 Embedding 基线，并对 59 道真实生成题完成结构、来源和精确重复审计。
- 编写端到端自动化验收脚本，真实跑通上传、异步解析、向量检索、题库生成、题目启用、学习作答、掌握度和历史记录；使用 Docker Compose 编排 Web、API、Worker、PostgreSQL、Milvus、Redis 和对象存储，并提供生产部署、备份恢复与故障排查文档。

## 可使用的真实数据

- 30 条固定标注查询的外部 Embedding 基线：Hit@1、Recall@5、MRR 均为 1.0，P50 约 400ms、P95 约 600ms。
- 59 道生成题：Schema 合法率 100%、来源关联率 100%、精确重复率 0%。
- 自动化端到端验收覆盖 8 个关键环节并成功完成 3 道题学习闭环。

以上指标只对应当前固定小样本和本机环境。检索语料只有 3 个 TCP 片段，因此面试或简历中必须同时说明范围，不表述为通用生产性能。59 道题的人工审核率尚未填写，不能声称人工通过率。
